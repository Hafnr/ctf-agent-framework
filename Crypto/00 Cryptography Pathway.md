## Classification questions

1. Is this representation, encryption, hashing, signing, or key exchange?
2. What is public, secret, reused, attacker-controlled, or oracle-accessible?
3. Which security assumption should hold?
4. Which assumption did the implementation violate?
5. What equation describes the observed data?
