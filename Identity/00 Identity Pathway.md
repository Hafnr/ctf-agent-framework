# Identity Pathway

Use this branch for Windows domains, LDAP, Kerberos, NTLM, trusts, service accounts, and enterprise identity challenges.

1. Start with [[Identity/01 Active Directory and Kerberos|Active Directory and Kerberos]].
2. For web federation, continue to [[Web/10 SSRF XXE JWT OAuth and SAML|JWT, OAuth, and SAML]].
3. For host-local escalation, use [[Playbook/Host and Privilege Escalation Playbook|Host and privilege escalation]].

Always record the current identity, source host, domain/forest, credential form, ticket lifetime, and authorization boundary before using a credential or ticket.
