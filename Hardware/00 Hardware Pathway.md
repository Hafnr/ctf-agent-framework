# Hardware Pathway

Start with [[Hardware/01 Firmware UART JTAG and SDR|Firmware, UART/JTAG, and SDR]]. Treat physical interfaces and radio transmissions as scoped resources: identify voltage, pinout, target ownership, and permitted frequencies before connecting or transmitting.

For extracted native code continue to [[Reverse/00 Reverse Engineering Pathway|Reverse Engineering]]. For filesystems and captures use [[Forensics/00 Forensics Pathway|Forensics]].
